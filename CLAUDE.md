# agent-skills

This repo contains agent skills installable via `npx skills add VohraAK/agent-skills@<skill-name>`.

Each skill lives in its own top-level directory with a `SKILL.md` and optional reference files.

When adding a new skill: create a new directory, add `SKILL.md` with valid frontmatter (`name`, `description`), update `README.md` if there are 3+ skills.
