# Base Rubric — All Niches

## Bullet Quality

Every experience/project bullet should have: **action verb + what + outcome or scale**

Flag:
- Weak openers: "worked on", "helped with", "assisted", "responsible for", "involved in"
- Zero-metric bullets in internships or significant projects (no numbers anywhere)
- Vague claims with no specifics ("improved performance", "built a system")

Don't flag:
- Short bullets that are already clear and specific
- Missing metrics on course projects or short exploratory work
- Passive voice in one bullet if content is otherwise strong

## Summary / Objective

Flag:
- "Passionate about technology / software / AI"
- "Eager to learn", "fast learner", "team player", "hard worker"
- Generic statements with no concrete signal
- Missing summary entirely only if experienced (1+ yr) — student CV summary is optional

Good summary: target role + strongest differentiator + one concrete signal

## Skills Section

Flag:
- Obvious filler: MS Office, Google Docs, Google Slides
- Tools listed that aren't relevant to target niche
- Glaring omissions for stated niche (e.g., ML role with no mention of numpy/pandas/sklearn)

Don't flag:
- Short skills list on a student CV — better sparse and honest than padded

## GitHub / Portfolio

Flag:
- No GitHub link in header (for any CS role)

Don't flag:
- No personal website (nice to have, not required)

## GPA

- Show if 3.5+ (or equivalent top-tier threshold for non-US grading)
- Omit if below — don't flag absence
- Flag if shown and below 3.5 with no compensating signal

## Experience Level Check

Detect from CV:
- Total months of work experience (internships, research, jobs)
- < 12 months → student/new grad
- 12+ months → experienced

This determines:
- Which section order to enforce (see ats-guidelines.md)
- Whether thin experience bullets are flagged or excused
- Whether a summary is expected
