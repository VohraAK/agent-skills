# Niche Rubrics

## Niche Detection Signals

| Niche | Strong signals |
|-------|---------------|
| SWE (Backend/Fullstack) | REST APIs, databases, system design, web frameworks |
| ML/AI Engineering | model training, inference, pipelines, TF/PyTorch/sklearn |
| Data Science | statistical analysis, SQL, EDA, business insights, visualization |
| Systems / Low-level | C, C++, Rust, OS, compilers, memory management, performance |
| Security | CTFs, penetration testing, vulnerability research, OSCP, Burp |
| DevOps / SRE | CI/CD, Kubernetes, Terraform, uptime, infrastructure, Docker |
| NLP / Research | transformers, fine-tuning, benchmarks, HuggingFace, papers |

---

## SWE (Backend / Fullstack)

Flag if missing:
- No scale indicators in experience bullets (users served, requests/sec, latency numbers)
- No mention of architecture or system design decisions in significant projects
- Projects with no deployed/functional outcome described

Don't flag:
- Missing frontend skills for backend-focused role
- No system design experience on a student CV

---

## ML / AI Engineering

Flag if missing:
- No model performance metrics (accuracy, F1, AUC, etc.) on ML projects
- No mention of dataset size or data pipeline
- No deployment or inference context for production-claimed projects
- Skills section omits core stack (numpy, pandas, sklearn, PyTorch or TensorFlow)

Don't flag:
- Missing MLOps tools on a student CV
- No cloud ML platform experience if local training is described

---

## Data Science

Flag if missing:
- No SQL anywhere (red flag for most DS roles)
- No business impact framing on analysis projects (what decision did it inform?)
- No statistical method named (regression, clustering, hypothesis testing, etc.)

Don't flag:
- Missing deep learning experience (not always required for DS)
- No visualization tool listed if analysis work is described

---

## Systems / Low-level

Flag if missing:
- No performance numbers in systems projects (latency, throughput, memory footprint)
- No mention of language-level decisions (why C++ vs C, memory model, etc.) in significant projects
- Skills section omits relevant low-level languages

Don't flag:
- No web or cloud experience — irrelevant to this niche
- Missing Python if systems work is clearly C/C++/Rust

---

## Security

Flag if missing:
- No concrete wins: CTF placements, CVEs, bug bounty payouts, pentest scope
- Tools listed without context of how they were used
- Vague "interested in security" language with no evidence

Don't flag:
- Missing cloud or web dev experience
- No formal certification if practical experience is present

---

## DevOps / SRE

Flag if missing:
- No reliability or uptime metrics in experience
- No CI/CD pipeline described
- No IaC tool mentioned (Terraform, Ansible, Pulumi, etc.)

Don't flag:
- Missing deep application code experience
- No Kubernetes if smaller-scale infra is described

---

## NLP / Research-adjacent

Flag if missing:
- No benchmark results or evaluation metrics on NLP projects
- No dataset or model described by name
- Research project with no outcome or finding stated

Don't flag:
- No production deployment experience (research-adjacent roles don't always require it)
- Missing software engineering depth if research work is strong
